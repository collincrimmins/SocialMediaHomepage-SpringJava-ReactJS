# Welcome to my Social-Media Homepage project

## Features
1) Create an Account (secured with JWT Tokens)
2) Publish Posts
3) View a Chronological Infinite Scroll Homepage feed

## Stack
Spring Boot 3.0
- Java 17

MySQL Database
- Spring JPA & Hibernate

ReactJS
- Frontend
